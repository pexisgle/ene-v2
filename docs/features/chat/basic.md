# 基本チャット

テキストを通じてAIと雑談や相談を交わし、話題の文脈を自然に保ったままスムーズに対話を続けられます。

## 具体的な振る舞い

1. [ホストへ接続](../hosting/README.md)し、[利用するAIモデルを設定](../settings/models.md)したうえで、クライアントの対話画面を開きます。
2. メッセージを送信すると、これまでの対話の文脈を踏まえた的確な応答が得られます。
3. 続けて質問を重ねたり、前提条件を補足したりしながら、自然な流れでやりとりを深められます。
4. テキスト入力に加え、音声対話やクライアント上での操作入力など、多彩なインターフェースに対応します。
5. 会話履歴はホスト側で一元管理されます。同一ホストへ別の端末から接続した場合や再接続した場合にも、保持されている範囲の履歴をシームレスに確認できます。なお、会話履歴の保存は[記憶機能](../memory/README.md)とは独立した仕組みであり、すべての会話ログを永久に保存し続けることを前提とはしていません。過去のログ自体が破棄された後であっても、抽出・保存された長期記憶をもとに対話を継続できます。
6. 会話履歴はコンパニオンごとに個別に管理されます。他のコンパニオンへ伝える情報や相手は、[記憶機能](../memory/README.md)の方針に従い、文脈やユーザーの意向を踏まえて適切に判断されます。
7. 対話を通じて蓄積されたユーザーの好みや思い出は、以後の会話や作業に自然と反映されます。記憶された内容の確認・訂正・忘却や、共有についての意向も、対話の中で伝えられます。

参考：[AIRI](../../references.md#airi) の日常的に話しかけられる対話インターフェース。会話の文脈維持や履歴管理の分離方針はene独自の設計です。
