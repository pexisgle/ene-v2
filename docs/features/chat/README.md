# Chat

シンプルなテキスト対話から、キャラクター固有の個性を活かした情緒豊かな会話までを包括する領域です。音声対話、Web検索、タスクの依頼、キャラクターからの自発的な声かけなど、あらゆる体験がこの対話画面を基点としてシームレスにつながります。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [基本チャット](basic.md) | 文脈を自然に保ちながらテキストでスムーズにやりとりを行う |
| [記憶機能](../memory/README.md) | ユーザーの好みや思い出を記憶し、覚えた内容の確認や訂正を行う |
| [ホストとクライアント](../hosting/README.md) | 複数端末から同一ホストへ接続し、会話や作業の文脈を引き継ぐ |
| [キャラクターとの対話](character.md) | 定義された口調や性格を反映した、臨場感ある対話を楽しむ |
| [Web検索](../tools/search.md) | 会話の流れの中で、必要な最新情報を素早く収集・参照する |
| [音声対話](../voice/README.md) | マイクを通じて自然に話し、キャラクター固有の声で返答を受け取る |
| [タスク依頼](../task/request.md) | 依頼したい作業を対話で伝え、進捗や最終報告を確認する |
| [スケジュール実行](../autonomy/schedule.md) | 対話で取り決めた日時に合わせてキャラクターから声をかけ、作業を進める |
| [自発的な働きかけ](../autonomy/watch-over.md) | 作業状況や画面の様子を察して、キャラクターから提案や雑談を始める |
