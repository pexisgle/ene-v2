# キャラクターとの対話

登録された口調や語尾、「心」の設定を反映し、まるで実在するキャラクターと接しているかのような臨場感ある[チャット](basic.md)を楽しめます。

## 具体的な振る舞い

1. [作成または取り込んだキャラクター](../character/create.md)を選択して読み込みます。
2. メッセージを送信すると、対話の文脈を理解したうえで、そのキャラクター固有の語彙や語尾、感情を反映した返答が届きます。
3. キャラクターの世界観やユーザーとの関係性を保ちながら、違和感のない自然な対話を深められます。
4. 言葉によるやりとりにとどまらず、[デスクトップ上での多彩な仕草やリアクション](../character/desktop.md)を通じて、より親密なインタラクションを楽しめます。

参考：[AIRI](../../references.md#airi) における固有のキャラクター性を備えた対話体験。
