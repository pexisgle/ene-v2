# 機能の拡張

外部ツールやMCPサーバー、タスク実行プラグイン（「手」）、知覚・身体表現に至るまで、様々な機能を自由に追加・差し替えできる拡張領域です。

「Everything is a plugin」（あらゆる構成要素がプラグインである）という考え方を掲げ、必要な機能を後から柔軟に追加・交換できるプラットフォームを目指します。

## 拡張の対象

1. **「手」のプラグイン（ツール・MCP・タスク実行）**:
   - 外部APIツールやMCPサーバーを接続し、作業実行側が扱える道具を増やします。
   - プラグインAPIを通じて独自のタスク実行エンジンを追加でき、外部のACP（Agent Client Protocol）対応エージェントをラップした「手」もプラグインとして簡単に組み込めます。
   - Wasmプラグイン（Extism）による安全に隔離されたプロバイダ・ツール実行にも対応します。
2. **「目」の拡張（クライアント側の知覚センサー追加）**:
   - クライアント側で動作し、「目」へ送る環境情報（エディタやブラウザの文脈など）を増やす知覚プラグインを追加できます。
3. **「体」の拡張（クライアント側のモーション・挙動追加）**:
   - クライアント側で動作する待機モーション、発話時の仕草、表情リアクションなど、アバターの身体表現を拡張できます。

## 具体的な振る舞い

1. 利用したい拡張プラグイン（プロバイダ、MCP、「手」、知覚センサー、モーション等）を選んで有効化します。
2. 有効化後は、[権限とデータの管理](../settings/permissions.md)の判定パイプライン（機械的許可 → Decision API → 必要時のみ承認）に従って安全に利用できます。
3. 設定画面から、拡張機能ごとの有効化・無効化や差し替えをいつでも自由に行えます。

参考：[nanobot](../../references.md#nanobot) のMCP連携、および [deepseek-harness](../../references.md#deepseek-harness) のプラグイン拡張思想。
