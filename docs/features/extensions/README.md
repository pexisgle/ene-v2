# 機能の拡張

外部ツールやMCPサーバー、タスク実行エンジン（ハーネス）をはじめ、キャラクターの感覚や表現に至るまで、様々な機能を自由に追加・差し替えできる拡張領域です。

将来的には **"Everything is a plugin"**（あらゆる構成要素がプラグインである）の思想を掲げ、新機能の追加だけでなく、既存機能の挙動を一部フック・変更できる柔軟なプラットフォームを目指します。

## 拡張の対象（手・目・体の全方位強化）

1. **「手」の強化（ツール・MCP・ハーネス）**:
   - 外部APIツールやMCPサーバーを接続し、作業実行側が扱える道具を拡充します。
   - 内蔵のRigエンジンに加え、ACP（Agent Client Protocol）等を通じた外部の特化型タスク実行ハーネス（コーディング特化エンジン等）への差し替えに対応します。
   - Wasmプラグイン（Extism組み込み）による安全な隔離実行もサポートします。
2. **「目」の強化（知覚センサーの追加）**:
   - 取得できる情報を増加させる知覚プラグインを追加します（例: 特定のIDEやブラウザ専用の監視連携、OSイベントのフック、ウィンドウメタデータの高度な取得など）。
   - 「目」がより高解像度な環境情報を捉えることで、「頭」がユーザーの状況をより深く察して自発的に活動できるようになります。
3. **「体」の強化（モーション・挙動の追加）**:
   - キャラクターの待機モーション、発話時の仕草、感情に応じたリアクション、ウィンドウ連携の演出など、アバターの身体表現をプラグインとして追加・拡張できます。

## 具体的な振る舞い

1. 自作やコミュニティ製をはじめ、利用したい拡張プラグイン（ツール、知覚センサー、モーション、ハーネス等）を選択して有効化します。
2. 接続や有効化の際には、実現できる機能、アクセス対象、送信されるデータの種類・用途・送信先をわかりやすく提示します。有効化後は、sandbox の内側で完結する操作は確認なし、外に出る操作は[自動判定](../settings/permissions.md)、弾かれた場合だけ承認を求めます。
3. コンパニオン（「頭」）や作業エージェント（「手」）が、許可された範囲内でこれらの拡張機能を自律的に呼び出します。
4. 設定画面から、拡張機能ごとの有効化・無効化、連携の解除、別のエンジンやモーションへの差し替えなどをいつでも自由に行えます。

## 制約と検討事項

- 拡張機能にも[権限とデータの管理](../settings/permissions.md)を適用します。eneが仲介するツール・秘密情報はホストで制限し、外部ハーネスの自前機能はOSやハーネスへ委譲する範囲を明示します。
- 端末内の機能の提供には、対応クライアントの稼働と端末ごとの明示的な許可が必要です。
