# スケジュール実行

指定した日時や定期的なスケジュールに合わせて、キャラクターが自発的に声をかけたり、任された作業を進めたりします。スケジュールの管理と実行状態の保持は常時稼働する[ホスト](../hosting/README.md)が担います。

## 具体的な振る舞い

1. コンパニオンとの対話を通じて、依頼したい作業内容や実行タイミング、結果の報告方法を伝えると、コンパニオンが自動的にスケジュールを設定します。許可済みの機能範囲内であれば、個別の権限ルールを都度作成する必要はありません。
2. 指定の時刻になると、任された作業を事前の再確認なしで自律的に進め、進捗の報告や状況に応じた提案を行います。
3. 処理結果や、ユーザー自身の判断が必要な事項をキャラクターから報告します。新たなリソースへのアクセスや重要な判断が求められる場合は、該当する工程のみを保留とし、調査や下書きなど自立して進められる作業は継続します。クライアントが未接続の場合も、結果や保留事項はホスト上に保持され、再接続時にまとめて通知されます。未決事項を実行ごとに重複して通知することはありません。
4. スケジュールや作業内容はいつでも自由に変更でき、タスクの一時停止や再開も対話の中で簡単に行えます。

## 制約と検討事項

- ホストが稼働している間は、クライアントが未接続でもホスト側のスケジュール実行やタスク処理を継続します。操作対象の端末がオフラインの場合は、その端末に依存する処理を保留します。マシンの停止・スリープやホストの再起動に伴う未実行分の扱いなど、運用上の詳細は設計段階で具体化します。
- ユーザーの集中を妨げない声かけの頻度やタイミングの判定手法は現在検討中です。クライアント不在時に蓄積された通知の再接続時における最適な提示方法や、プッシュ通知の連携方式について順次具体化を進めます。

参考：[Hermes Agent](../../research/references.md#hermes-agent) のスケジュール実行、および [Grok Bot](../../research/references.md#grok-bot) の継続タスク・通知機能。キャラクターによる声かけを通じた演出はene独自の設計です。
