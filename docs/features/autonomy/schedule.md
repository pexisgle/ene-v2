# スケジュール実行

「頭」（キャラクターAgent）が日常会話の中で自ら登録した予定やリマインドに合わせて、指定時刻に発火して声をかけたり、作業を進めたりします。スケジュールの管理と実行状態の保持は常時稼働する[ホスト](../hosting/README.md)が担います。

## 具体的な振る舞い

1. 「頭」がユーザーとの会話や文脈から「あとで知らせよう」「定期的に確認しよう」と判断した際、自らスケジュールを登録します。
2. 登録された時刻になると、ホストが「頭」に予定の内容や理由をコンテキストとして投入し、「頭」がキャラクター本来の思考の中で発話や「手」への作業発注を行います。
3. クライアントが切断中でもホスト側でスケジュールは維持され、再接続時に対話の中で自然に報告されます。

## 親エージェント向けツール

親エージェント（頭）は日常会話の中でスケジュールを自律的に登録・確認・解除できます。
- `schedule_create(title, instruction, run_at, cron_expr)`: 予定やリマインドを登録
- `schedule_list()`: 登録中スケジュール一覧を取得
- `schedule_cancel(schedule_id)`: スケジュールを解除

参考：[Hermes Agent](../../references.md#hermes-agent) のスケジュール実行、および [Grok Bot](../../references.md#grok-bot) の継続タスク・通知機能。
