# 自発的な働きかけ（見守り）

軽量・高速・安価なモデルで動く「目」エージェントが、ユーザーの入力状況、操作環境、時間経過などの情報を常に読み込み、**「頭」に伝える価値があると判断した情報だけを選別して「頭」へ渡す**ことで、自然な声かけや見守りを実現します。

## 具体的な振る舞い

1. 「目」（知覚評価エージェント）による常時観測と選別:
   - クライアントから送られるアクティブウィンドウの変化や入力状況、前回のやり取りからの時間経過などの情報を、「目」が軽量なモデルで常時評価します。
   - 変化のない情報や重複を省き、日常の小さな変化も観測した事実として短くまとめて「頭」へ渡せます。
   - 通常の自動報告は最大1分に1回です。作業を止めるエラーや画面の反応確認などの重要な観測は別に待ち行列へ入れ、「頭」が次に空いたとき優先して渡します。
2. 「頭」による応答判断:
   - 報告を受けた「頭」は、ユーザーの話題や指示（「いま集中しているから静かにして」等）、観測の確かさ、今伝える価値を踏まえ、返答に取り入れるか、無言の仕草にするか、静観するかを決めます。
   - 返答では、ユーザーの目的に関係する事実に絞ります。たとえば画面が見えているかの確認には、見えていることを短く伝えます。
3. 複数コンパニオン存在時の声かけ:
   - 画面上に複数のコンパニオンが常駐している場合、それぞれの性格や文脈に応じて応答するかどうかを自律的に判断します。
4. 対話へのシームレスな移行:
   - 声かけに対してユーザーの返答があると、通常の[対話（Chat）](../chat/README.md)と同様に双方向の会話へ移行します。

## 制約と検討事項

- 画面情報の取得は端末内のクライアント上で行われ、軽量なメタデータやローカル解析を優先してプライバシーと通信負荷を抑えます。
