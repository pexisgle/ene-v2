# Autonomy

あらかじめ設定したスケジュールやユーザーの作業状況をきっかけとして、キャラクターが自発的に声をかけたり、任された作業を自律的に進めたりする領域です。[許可された機能と権限の範囲](../settings/permissions.md)内で自律的に動作するため、日常的な動作のたびに承認を求めることはありません。新たなリソースへのアクセスや重要な判断が必要な場合にのみ対話を通じて相談し、ユーザーの離席中であっても自立して進められる作業は滞りなく継続します。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [スケジュール実行](schedule.md) | 指定した日時や定期的な予定に合わせて自発的に声をかけ、作業を進行する |
| [自発的な働きかけ](watch-over.md) | 作業状況や画面の状態、これまでの文脈を察して提案や雑談を始める |
| [基本チャット](../chat/basic.md) | 声かけをきっかけとして、通常の対話へと自然につなげる |
| [作業の依頼](../task/request.md) | 自律的に任せる作業内容と、その進捗・最終報告を確認する |
| [ホストとクライアント](../hosting/README.md) | 実行基盤の配置場所と、端末の停止・切断時における作業の継続条件を確認する |
| [権限とデータの管理](../settings/permissions.md) | 自律実行で利用可能な操作や情報、データ送信の範囲を管理する |
