# Autonomy

「目」が捉えたユーザーの入力状況や時間経過、あるいは「頭」自身が登録したスケジュールをきっかけとして、キャラクターが自発的に声をかけたり、任された作業を進めたりする領域です。

軽量・高速・安価なモデルで構成された「目」（知覚評価モジュール）が情報を常時読み込み、価値のある変化や文脈があると判断した情報だけを「頭」（キャラクターAgent）へ渡します。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [自発的な働きかけ（見守り）](watch-over.md) | 「目」が入力状況や時間経過から価値のある変化を選び出し、「頭」へ渡して自発的な声かけを行う |
| [スケジュール実行](schedule.md) | 「頭」が日常対話の中で自ら登録した予定やリマインドをトリガーに自律動作する |
| [対話（Chat）](../chat/README.md) | 声かけをきっかけとして、通常の対話へと自然につなげる |
| [作業の実行](../task/request.md) | 「手」に自律的に任せる実務の進行と、定期的な情報交換 |
| [ホストとクライアント](../hosting/README.md) | 実行基盤の配置場所と、端末切断時の継続条件を確認する |
| [権限とデータの管理](../settings/permissions.md) | 自律実行で利用可能な操作や判断ポリシーを管理する |
