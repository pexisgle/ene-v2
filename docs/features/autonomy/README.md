# Autonomy

あらかじめ設定したスケジュールや、「目」が捉えたユーザーの作業状況、内部タイマー（Tick）をきっかけとして、キャラクターが自発的に声をかけたり、任された作業を自律的に進めたりする領域です。

AITuberのエージェントループを参考に、「目」（知覚要約モジュール）からの情報提供と内部タイマーをもとに、「頭」（キャラクターAgent）が状況を評価し、**話しかける（Speak）／作業する（Work）／静かに見守る（NOOP）** を自律的に選択します。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [スケジュール実行](schedule.md) | 指定日時や定期予定、前回の活動からの時間経過（Tick）を「頭」へ注入して自律動作する |
| [自発的な働きかけ（見守り）](watch-over.md) | 「目」が捉えた作業状況や画面の変化を要約注入し、文脈に応じた声かけや提案を行う |
| [対話（Chat）](../chat/README.md) | 声かけをきっかけとして、通常の対話へと自然につなげる |
| [作業の実行](../task/request.md) | 「手」に自律的に任せる実務の進行と、双方向の連携 |
| [ホストとクライアント](../hosting/README.md) | 実行基盤の配置場所と、端末の停止・切断時における作業の継続条件を確認する |
| [権限とデータの管理](../settings/permissions.md) | 自律実行で利用可能な操作や情報、データ送信の範囲を管理する |
