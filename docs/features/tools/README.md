# Tools

AIが外部から最新情報を収集したり、実行環境やクライアントの機能を操作したりする際に用いるツール群を管理する領域です。

## 役割とツールの分担

### 親エージェント（頭）のツールセット

親エージェント（頭）は会話テンポを維持するため、記憶・作業委託・承認・スケジュール・クライアント能力のツールを保持します。

| カテゴリ | ツール名 | 役割 |
| :--- | :--- | :--- |
| **記憶 (Mind)** | `mind_recall(query, limit)` | 過去の関連エピソード記憶を検索（明示的想起） |
| | `mind_read(memory_id)` | 特定記憶の詳細と関係性コンテキストを閲覧 |
| | `mind_update(action)` | 記憶の追加・訂正・忘却（優先度の引き下げ） |
| **作業委譲 (Hands)** | `start_work(instruction)` | プラグイン化された「手」へ実務タスクを依頼 |
| | `send_work(work_id, text)` | 進行中タスクへの追加入力や方針変更の伝達 |
| | `stop_work(work_id)` | 進行中タスクの中断を要求 |
| **承認 (Approval)** | `resolve_approval(request_id, decision)` | 会話の中でユーザーがOK・拒否したと判断した際に、保留中の承認を確定する |
| **クライアント能力** | クライアントが登録した能力ツール | アクティブクライアントが `RegisterClient` で登録した能力（モーション指示や端末操作等）を動的に公開・実行 |
| **自律スケジュール** | `schedule_create(title, instruction, run_at, cron_expr)` | タイマーや定期リマインドを登録 |
| | `schedule_list()` | 登録済みスケジュール一覧を取得 |
| | `schedule_cancel(schedule_id)` | スケジュールを解除 |

タスク実行側の「手」は、プラグインAPIや外部MCPサーバーから提供されるツール群を用いて実務を遂行します。
