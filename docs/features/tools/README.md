# Tools

Web検索をはじめ、AIが外部から最新情報を収集したり、実行環境や各種サービスを安全に操作したりする際に用いるツール群を管理する領域です。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [Web検索](search.md) | 対話の流れの中で必要な外部情報をリアルタイムに検索・参照する |
| [調査の依頼](../task/research.md) | 検索やローカル資料を活用して情報を網羅的に収集し、比較・分析する |
| [機能の拡張](../extensions/README.md) | 外部ツールやMCPサーバーを新たに追加・接続し、ツールの幅を広げる |
