# Tools

AIが外部から最新情報を収集したり、実行環境や各種サービスを安全に操作したりする際に用いるツール群を管理する領域です。ツールは将来的に順次追加・拡張される枠組みであり、本領域はその基盤的な役割を示します。

## 役割とツールの分担

- **キャラクターAgent（頭）が持つツール**:
  - Web検索や現在日時の確認など、対話の合間に即座に利用できる軽量・簡潔なツールに絞って保持します。
- **タスク用Agent（手）が持つツール**:
  - 思考・推論やマルチステップの処理、ファイル操作など、多少考えることが必要な実務操作はすべて[タスク用Agent（手）](../task/request.md)へ委譲します。
- **ユーザー体験（ボイスメイン）**:
  - 本ソフトウェアはチャットUIではなく**ボイス対話がメイン**であるため、ツール実行中を示すリッチなUI表示や、キャラクターによる形式的な「調べてみるね」といった前置き発話を必須とはせず、自然な会話の流れの中でツール結果を反映します。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [Web検索](search.md) | 対話の流れの中で必要な外部情報をリアルタイムに検索・参照する |
| [作業の依頼](../task/request.md) | 「手」（タスク用Agent）を通じて思考や作業を要する実務を実行する |
| [機能の拡張](../extensions/README.md) | 外部ツールやMCPサーバーを新たに追加・接続し、ツールの幅を広げる |
