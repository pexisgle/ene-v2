# Web検索

対話の途中で最新情報や外部の知見が必要になった際、AIが自律的に、あるいは指示に応じてWeb検索を行い、参照元の出典を明示したうえで回答します。なお、複数の情報源を横断して網羅的な比較・整理を行う本格的なリサーチは[調査の依頼](../task/research.md)で扱います。

## 具体的な振る舞い

1. 利用したい検索プロバイダを選択し、APIキーなどの必要な接続設定を行います。
2. ユーザーが質問を投げかけるか、あるいは明示的に「〜について検索して」と指示します。
3. AIが文脈から最新情報の必要性を自律的に判断、または指示に従い、設定された検索エンジンを用いて関連情報を速やかに収集します。
4. 収集した情報に基づき、参照元のWebリンクや出典を明記したうえで分かりやすく回答します。該当する情報が得られなかった場合は、見つからなかった旨とその理由を丁寧に伝えます。

参考：[nanobot](../../research/references.md#nanobot) の検索プロバイダ選択と出典表示。対話の流れから自律的に検索の要否を判断する挙動はene独自の仕様です。
