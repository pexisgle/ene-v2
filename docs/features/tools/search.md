# Web検索

対話の途中で最新情報や外部の知見が必要になった際、キャラクターAgentが自律的に、あるいは指示に応じてWeb検索を行い、参照元の出典を踏まえて回答します。なお、複数の情報源を横断して網羅的な比較・整理を行うような思考を要する本格的なリサーチは[作業の依頼](../task/request.md)を通じて「手」（タスク用Agent）が担当します。

## 具体的な振る舞い

1. 利用したい検索プロバイダを選択し、APIキーなどの必要な接続設定を行います。
2. ユーザーが質問を投げかけるか、あるいは「〜について調べて」と指示します。
3. キャラクターAgentが文脈から最新情報の必要性を自律的に判断、または指示に従い、設定された検索エンジンを用いて関連情報を速やかに収集します。
4. ボイス対話の流れの中で自然に検索結果を反映して回答します（「調べてみるね」などの前置きを必須とせず、スムーズに返答します）。チャット画面上でも参照元のリンクや出典を確認できます。該当する情報が得られなかった場合は、その旨を簡潔に伝えます。

参考：[nanobot](../../references.md#nanobot) の検索プロバイダ選択と出典表示。対話の流れから自律的に検索の要否を判断する挙動はene独自の仕様です。
