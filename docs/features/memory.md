# 記憶とスキル

この文書では [用語集](../terms.md) の定義に沿って、コンパニオンが日々の対話や作業から出来事や作業手順を蓄え、活かしていく機能仕様をまとめます。
記憶やスキルはホスト側でコンパニオンごとに永続化されるため、端末を切り替えたり利用するモデルを変更したりしても失われません。
作者が決める静的な人格設定と日々の交流で蓄積する記憶は分けて管理し、配布用のキャラクターパッケージには蓄積した記憶を含めません。

## 個別と共有のエピソード記憶

記憶システムの中心は好みや思い出などの出来事を残すエピソード記憶で、コンパニオンごとの個別エピソードと複数コンパニオン共通の共有エピソードの 2 つの保存範囲で扱います。
エピソード記憶では保存項目をあらかじめ固定せず、出来事の要約や当時の感情、重要度、いつ誰から得たかという由来を文脈に沿って抽出します。
呼び方や譲れない前提のように常に押さえておくべき事実は、この重要度を最大にすることで毎回検索しなくても会話の前提として常に参照されるようにします。
共有エピソードでは複数のコンパニオンが共通して知っておくべき基本属性や共通事項を、個別エピソードと同じ仕組みのまま保存範囲だけを分けて管理します。
特定のコンパニオンと交わした個別の思い出まで無条件に共有せず、何を共有するかは話題の性質や利用者の意向に沿って判断します。

## 記憶の整理と自然な想起

記憶の整理は会話の圧縮に合わせて裏側で進み、[Mem0](../references.md#mem0) の記憶抽出・整理パイプラインのように会話から事実や好みを抜き出して既存記憶との重複や矛盾を整えます。
想起では [Generative Agents](../references.md#generative-agents) の想起モデルを取り入れ、出来事の重要度、経過時間による減衰、今の話題との関連度を組み合わせて思い出す内容を決めます。
この重み付けにより、些細な日常会話は時間とともに表に出にくくなる一方、強い感情を伴う出来事や約束は長く保たれ、古い出来事でも直接話題にされれば振り返ることができます。
検索候補に上がっただけでは最近使った扱いにせず、実際の発話や行動で参照された記憶だけを更新することで、無関係な記憶が優先され続ける偏りを防ぎます。
こうした想起は利用者から話しかけられたときに加え、「目」からの自発的な声かけやスケジュール実行が始まるときにも働き、その場面に合う記憶を呼び出します。

## 対話による確認・訂正・忘却

記憶の一覧画面は設けず、何を覚えているかの確認、誤りの訂正、忘れてほしい指示はすべてコンパニオンとの自然な対話の中で完結させます。
利用者から忘れるよう求められた記憶は想起の優先度を下げ、日常の対話で思い出しにくくします。

## スキル記憶と「手」への受け渡し

エピソード記憶とは別の機能として、[Hermes Agent](../references.md#hermes-agent) のスキル学習の仕組みを取り入れたスキル記憶を備えます。
作業の成功や対話での指示から再利用できる手順や注意点を自律的にまとめ、繰り返しの作業へ活かします。
普段の会話を受け持つ「頭」の文脈を軽く保つため、スキルの詳細は「手」が作業を始めるときに名前と概要の一覧から必要なものだけを選んで段階的に読み込みます。
「手」に作業を任せるときは [Letta](../references.md#letta) の記憶ブロック分離の考え方を取り入れ、必要な記憶だけを渡してエピソード記憶や人格設定の書き換え権限は与えません。
