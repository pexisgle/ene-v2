# 感情とキャラクターの成長

この文書では [用語集](../terms.md) の定義に沿って、コンパニオンが対話や出来事に応じて感情を変化させ、利用者との関係性や受け答えを育てていく機能仕様をまとめます。
感情や関係性、関心といった心の状態はホスト側でコンパニオンごとに永続化されるため、端末の切り替えや使用する LLM の変更をまたいでも途切れず引き継がれます。
作者が決める静的な人格設定と日々の交流で変化する心の状態は分けて管理し、配布するキャラクターには育った心の状態を含めません。

## 文脈に沿った感情の保持と時間変化

感情や関係性は好感度スコアや固定の計算ルールで決め打ちせず、会話や出来事から整理した心の状態と記憶を保持し、それらを対話や仕草へどう活かすかは LLM の文脈判断に任せます。
[SocioMind](../references.md#alpha-mind) のように人格・感情・関係・経験を結び付けて扱う要素を取り入れ、文脈に応じた自然な受け止め方を保ちます。
感情や気分は新しい発言や出来事に応じて更新され、会話の間が空くなど時間が経つにつれて、人格設定に基づく本来の落ち着いた気質へ自然と戻っていきます。
一方で、これまでの交流で築かれた関係性や関心は一時的な気分とは分けて保持し、時間が経っても急には失われないようにします。

## 表現への反映と一時的な仕草との区別

保持された心の状態は発話の言い回しや声の調子、デスクトップ上での表情や仕草を決める補助情報として活かします。
その場の発話に合わせて「体」へ送る一時的な表情や仕草の指示は、[AITuberKit](../references.md#alpha-mind) の表現連携のように応答と声・動きをつなぐ用途にとどめ、持続する心の状態そのものとは区別します。
この区別により、一時的に驚いたり照れたりした直後でも、相手との本来の関係性や落ち着いた気分が不自然にぶれずに保たれます。

## 交流を通じたキャラクターの成長

[Replika](../references.md#replika) のように日常の自然なやり取りから相手への理解が深まる体験を目指し、日々の対話と作業を通じて利用者一人ひとりに寄り添う受け答えや関係性がコンパニオンごとに育っていきます。
たとえばコンパニオンが返した短い進捗報告を利用者が喜んだ経験が次の作業報告へ活きるなど、一緒に経験した出来事や記憶の積み重ねが接し方の変化として表れます。
また [Kindroid](../references.md#kindroid) のように静的な人格設定と交流の中で育つ変化を分離する考え方を取り入れ、日々の会話だけで人格設定が書き換わらないまま心の状態と記憶へ成長を反映します。
なお、作者が設定した架空の背景や会話例は実体験とは分けて扱い、対話で実際に起きた出来事と混ざらないようにします。
