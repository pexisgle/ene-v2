# 音声対話

eneの中心となる対話体験で、クライアント端末のマイクを通じてキャラクターへ直接語りかけ、そのキャラクター固有の声による返答を耳で受け取ることができます。[ホスト](../hosting/README.md)側にマイクやスピーカーを用意する必要はなく、手元のクライアント端末だけで低遅延な音声対話が完結します。

## 具体的な振る舞い

1. 音声対話には「STT（音声認識） ➔ キャラクターAgent ➔ TTS（音声合成）」のパイプラインに加え、GPT-Live や Gemini Live API などのリアルタイム双方向音声APIも選択できます。
2. 音声入力は、発話を自動検出する常時発話検出（VAD）と、キーを押している間だけ聞き取るプッシュ・トゥ・トーク（Push-to-Talk）を切り替えられます。
3. キャラクターの発話中にユーザーが割り込んだ場合は、発話を中断してユーザーの聞き取りへ切り替えます。
4. 音声の出力に合わせて、クライアント上のアバター（VRM等）がリップシンク（口パク）や発話モーションを連動させます。
5. 複数のコンパニオンが同一画面に常駐している場合も、それぞれのキャラクターの文脈や名前呼びに応じて自然に会話に加わります。
6. 音声入力と読み上げは独立してオン・オフでき、周囲の環境に応じてテキスト対話へ柔軟に切り替えられます。

## 制約と検討事項

- 音声認識と音声合成の処理場所（端末ローカルかクラウドか）は、採用するエンジンとクライアントの環境に応じて決まります。
- クライアント端末のマイク・スピーカーのアクセス権限はOSの許可方針に従います。
