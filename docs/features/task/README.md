# Task

キャラクターに実務や調査を依頼し、進捗や最終報告を対話の中で確認するための領域です。日常の対話から自然に作業を任せ、サブエージェントによる実行後も、コンパニオンに詳しい説明や追加の作業を依頼できます。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [作業の依頼](request.md) | 対話を通じてゴールを伝え、ファイル整理・資料作成・ツール操作などの実務を任せる |
| [記憶機能](../memory/README.md) | 作業の文脈や学習した手順を、以後の依頼へ適切に引き継ぐ |
| [ホストとクライアント](../hosting/README.md) | 作業の実行環境と、端末の切り替えや切断時における処理継続の条件を確認する |
| [調査の依頼](research.md) | 複数の情報源を横断リサーチし、比較表や要約レポートなどで調査結果を確認する |
| [Web検索](../tools/search.md) | 調査や実務に必要な最新情報を外部から収集する |
| [スケジュール実行](../autonomy/schedule.md) | 指定した日時に合わせて、定型的な作業を自律的に進行させる |
| [機能の拡張](../extensions/README.md) | より高度な実務に必要な外部ツールやタスク実行エンジンを追加・接続する |
