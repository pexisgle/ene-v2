# Task

キャラクターが考えたことやユーザーからの依頼を実際に実行に移す**「手」（作業実行プラグイン）**を管理する領域です。

対話や状況判断に専念する「頭」（キャラクターAgent）と、実務を自律実行する「手」を分離し、定期的な情報交換を通じて協調することで、作業中であっても普段通りの自然な対話を妨げません。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [作業の実行（「手」の役割）](request.md) | 「頭」からの依頼をプラグイン化された「手」へ任せ、定期的な情報交換で実務を進行・報告する |
| [記憶機能](../memory/README.md) | 作業の文脈やHermes方式のスキルを以後の作業へ引き継ぐ |
| [ホストとクライアント](../hosting/README.md) | 作業の実行環境と、端末を閉じた際の自律継続の条件を確認する |
| [調査の依頼](research.md) | 「手」が担う作業の具体例（Webやローカル資料の横断リサーチ） |
| [Web検索](../tools/search.md) | 調査や実務に必要な最新情報を外部から収集する |
| [スケジュール実行](../autonomy/schedule.md) | 「頭」が自ら登録した予定に合わせて自律的に作業を進行させる |
| [機能の拡張](../extensions/README.md) | プラグインAPIを通じてACPラッパー等の「手」を追加・差し替える |
