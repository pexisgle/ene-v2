# Task

キャラクターが考えたことやユーザーからの依頼を実際に実行に移す**「手」（作業実行）**を管理する領域です。

対話や状況判断に専念する「頭」（キャラクターAgent）と、実務を自律実行する「手」（タスク用Agent）を明確に分離し、両者がリアルタイムに協調することで、作業中であっても普段通りの自然な対話や自発的な活動を妨げません。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [作業の実行（「手」の役割）](request.md) | 「頭」で考えたことや対話での依頼を「手」に任せ、自律的に実務を進行・報告する |
| [記憶機能](../memory/README.md) | 作業の文脈やHermes方式のスキルを以後の作業へ引き継ぐ |
| [ホストとクライアント](../hosting/README.md) | 作業の実行環境と、端末の切断時における自律継続の条件を確認する |
| [調査の依頼](research.md) | 「手」が担う作業の具体例（Webやローカル資料の横断リサーチ） |
| [Web検索](../tools/search.md) | 調査や実務に必要な最新情報を外部から収集する |
| [スケジュール実行](../autonomy/schedule.md) | 指定日時や定期予定に合わせて自律的に作業を進行させる |
| [機能の拡張](../extensions/README.md) | 「手」が扱えるツールやMCPサーバー、タスク実行エンジンを追加・差し替える |
