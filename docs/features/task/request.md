# 作業の実行（「手」の役割）

「頭」（キャラクターAgent）で考えたことやユーザーからの依頼を、裏で実際に実行に移す役割を担うのが「手」（タスク用エージェント）です。

「頭」をユーザーとの対話やアクションの受け取りに専念させるため、軽い即答操作を除き、実務作業のすべてを「手」が引き受けて自律的に遂行します。

## 具体的な振る舞い

1. **タスクの発生と委譲**:
   - ユーザーがボイスや対話でゴールを伝えるだけでなく、**ユーザーからの指示がなくてもコンパニオン（「頭」）が自発的に判断してタスクを生やす（「手」に作業を任せる）ことが可能**です。
   - 軽い操作は「頭」自身で完結させますが、多少の思考やマルチステップの手順を要する作業はすべて「手」へと委譲されます。
2. **「頭」と「手」のリアルタイム双方向連携**:
   - 「頭」と「手」はお互いの状況をリアルタイムに適切に報告しあいます。
   - **ユーザーからの軌道修正**: タスクの実行中にユーザーから方針変更や追加の要望があった場合、「頭」から即座に「手」へ伝達されます。
   - **問題発生時の相談**: 「手」が実行中に問題点や未決の判断事項に直面した場合、直ちに「頭」に報告されます。「頭」は自らの文脈や性格に基づいて自律判断するか、または対話の流れの中で自然にユーザーへ相談を持ちかけます。
3. **作業中の並行対話**:
   - 「手」がバックグラウンドで作業を進めている最中であっても、ユーザーはコンパニオン（「頭」）と普段通り自由に雑談や相談を続けられます。
4. **結果の報告と柔軟な扱い（"成果物"の概念排除）**:
   - システムとして固定化された「成果物」という概念は設けません。
   - 作業完了時にどのような形でユーザーに結果を伝えるか（口頭で要約を伝える、ファイルを作成して保存する、画面に表示するなど）は、**すべて「頭」の自律的な判断に一任**されます。
5. **スキルの蓄積**:
   - 作業の遂行を通じて得られた有用な手順やノウハウは、[記憶機能](../memory/README.md)（HermesAgent方式のスキル）として自律的に蓄積され、次回の作業へとスムーズに引き継がれます。

技術上の継続・能力・停止の契約は[作業相手API](../../design/work.md)に定めます。

参考：[Grok Bot](../../references.md#grok-bot) の対話的な作業指示体験、[Hermes Agent](../../references.md#hermes-agent) のスキル自律学習。
