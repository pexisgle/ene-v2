# 作業の実行（「手」の役割）

「頭」（キャラクターAgent）が考えたことやユーザーからの依頼を、裏で実際に実行するのが「手」（タスク実行プラグイン）です。

「頭」をユーザーとの対話や判断に専念させるため、軽い即答操作を除き、実務作業は「手」に任せて非同期で進めます。「手」はホストが提供するプラグインAPIを通じて実装でき、外部のACP（Agent Client Protocol）対応エージェント等をラップしたプラグインも簡単に組み込めます。

## 具体的な振る舞い

1. タスクは、ユーザーがボイスや対話でゴールを伝えること、あるいはコンパニオン（「頭」）が自発的に必要と判断することから始まります。
   - 軽い操作は「頭」自身で完結させ、手順を要する実務作業はプラグインである「手」へ委譲します。
2. 「頭」と「手」は**定期的な情報交換**を通じて連携します。
   - 「手」の実行状況や途中経過は定期的に「頭」へ共有され、確認や判断が必要な事項があれば「頭」を通じて自然にユーザーへ相談します。
   - 対話の中でユーザーから方針変更や追加要望があった場合も、「頭」から「手」へ伝達されます。
3. 「手」がバックグラウンドで作業を進めている間も、ユーザーはコンパニオン（「頭」）と普段どおり自由に雑談や相談を続けられます。
4. 作業完了時にどのような形でユーザーに結果を伝えるか（口頭で要約を伝える、ファイルとして保存する等）は、「頭」の自律的な判断に任せます。
5. 作業を通じて得られた有用な手順やノウハウは、[記憶機能](../memory/README.md)（HermesAgent方式のスキル）として自律的に蓄積され、次の作業へ引き継がれます。

参考：[Grok Bot](../../references.md#grok-bot) の対話的な作業指示体験、[Hermes Agent](../../references.md#hermes-agent) のスキル自律学習。
