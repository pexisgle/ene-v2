# 調査の依頼

「手」（タスク用エージェント）が担う具体的な作業の一例として、Web上の情報や手元の資料など、複数の情報源を横断してリサーチを行い、意思決定や実務に直結する整理された比較表や要約レポートを受け取れます。進捗の確認や途中の軌道修正は、[作業の実行](request.md)と同様に対話の中でシームレスに行えます。

## 具体的な振る舞い

1. 対話を通じて、またはコンパニオン自身の自発的な判断により、調査したいテーマや知りたい論点を「手」に託します。
2. 「手」が[Web検索](../tools/search.md)や指定されたローカル資料を網羅的に調査し、多角的な情報を収集します。
3. 収集した情報から要点を整理・比較分析し、「頭」を通じてユーザーへ報告されます。詳しい説明や追加の深掘りリサーチの依頼も、[作業の実行](request.md)と共通の対話フローで行えます。

参考：[Claude Cowork](../../references.md#claude-cowork) のWeb・資料横断リサーチ。
