# Settings

接続先ホスト、利用するAIモデルや外部サービスを選択し、コンパニオンに任せる範囲を把握・変更するための設定領域です。LLMに限らず、TTS・STT・Embedding・MCP・ACPの接続を共通の接続モデル（種別ごとの設定）で管理します。sandbox の内側で完結する操作は確認なしで実行し、外に出る操作は自動判定、弾かれたときだけ承認を求めるため、日常的な作業で細かな権限設定を考える必要はありません。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [ホストとクライアント](../hosting/README.md) | 接続先・通信経路の選択、外部サービス側でのアクセス管理、通信状態の確認 |
| [AIの選択・接続](models.md) | 対話や実務タスクに用いるAIプロバイダおよびモデルの選択・接続設定 |
| [権限とデータの管理](permissions.md) | sandbox と自動判定、危険時の承認、ポリシーと常に承認した操作の編集 |
| [記憶機能](../memory/README.md) | 記憶した内容や共有先の確認、訂正・忘却の設定 |
| [対話（Chat）](../chat/README.md) | 設定したモデルを用いたキャラクター対話（テキスト・ボイス） |
| [Web検索](../tools/search.md) | 検索プロバイダの選定と、許可範囲内での検索クエリ送信 |
| [音声での対話](../voice/README.md) | 音声認識・合成エンジンの選択、マイク入力や読み上げの設定 |
| [タスクの依頼](../task/request.md) | 任された権限範囲内での自律作業の実行と、重要判断時の対話相談 |
| [Autonomy](../autonomy/README.md) | スケジュール実行や自発的な声かけで利用する情報・操作範囲の管理 |
| [機能の拡張](../extensions/README.md) | 外部ツール、MCPサーバー、タスク実行エンジンの接続・管理 |
