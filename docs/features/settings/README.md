# Settings

接続先ホスト、利用するAIモデルや外部サービスを選択し、コンパニオンに任せる権限やデータ連携の範囲を把握・変更するための設定領域です。アクセス対象やデータ送信範囲は各機能の利用開始時に分かりやすく提示され、日常的な作業において細かな権限設定や過度な承認確認を求めることはありません。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [ホストとクライアント](../hosting/README.md) | ホストへの接続・認証、接続端末の承認・取り消し、通信状態の確認 |
| [AIの選択・接続](models.md) | 対話や実務タスクに用いるAIプロバイダおよびモデルの選択・接続設定 |
| [権限とデータの管理](permissions.md) | 利用可能な機能とデータ送信範囲の把握、権限の変更・解除 |
| [記憶機能](../memory/README.md) | 記憶した内容や共有先の確認、訂正・忘却の設定 |
| [チャット利用](../chat/basic.md) | 設定したモデルを用いたテキスト対話 |
| [Web検索](../tools/search.md) | 検索プロバイダの選定と、許可範囲内での検索クエリ送信 |
| [音声での対話](../voice/README.md) | 音声認識・合成エンジンの選択、マイク入力や読み上げの設定 |
| [タスクの依頼](../task/request.md) | 任された権限範囲内での自律作業の実行と、重要判断時の対話相談 |
| [Autonomy](../autonomy/README.md) | スケジュール実行や自発的な声かけで利用する情報・操作範囲の管理 |
| [機能の拡張](../extensions/README.md) | 外部ツール、MCPサーバー、タスク実行エンジンの接続・管理 |
