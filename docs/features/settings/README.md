# Settings

接続先ホスト、用途別のAIモデルや外部サービスを選択し、コンパニオンに任せる範囲を最小限の設定で管理するための領域です。LLMに限らず、TTS・STT・Embedding・MCP・プラグインの接続を共通の接続モデルで管理します。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [ホストとクライアント](../hosting/README.md) | 接続先・通信状態の確認、クライアント能力の登録 |
| [AIの選択・接続](models.md) | 「頭」「手」「目」「Compaction/記憶」など用途別のモデル選択・接続設定 |
| [権限とデータの管理](permissions.md) | 機械的ルール・Decision API・自由文ポリシーによる最小限の承認制御 |
| [記憶機能](../memory/README.md) | 記憶や共有スコープの確認、訂正・忘却 |
| [対話（Chat）](../chat/README.md) | 設定したモデルを用いたキャラクター対話（テキスト・ボイス） |
| [Web検索](../tools/search.md) | 検索プロバイダの選定とクエリ送信 |
| [音声での対話](../voice/README.md) | 音声認識・合成エンジンの選択、マイク入力や読み上げの設定 |
| [タスクの依頼](../task/request.md) | 任された範囲内での自律作業の実行 |
| [Autonomy](../autonomy/README.md) | 「目」の見守りやスケジュール実行の管理 |
| [機能の拡張](../extensions/README.md) | 外部ツール、MCPサーバー、各種プラグインの接続・管理 |
