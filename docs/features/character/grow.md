# キャラクターの成長

日々の対話や共有した体験を通じて、キャラクターの性格傾向や感情の移ろいやすさ、ユーザーとの関係性が深まり、変化していく成長の仕組みです。

## 具体的な振る舞い

1. コンパニオンとの対話内容や、[共に経験した出来事の記憶](../memory/README.md)をもとに、成長機能がキャラクターの性格傾向や[感情システム](./mind.md)における関係性の変化を判断します。なお、記憶の保存処理が「心」の初期プロファイルを直接上書きすることはありません。
2. 蓄積された変化に応じて感情パラメータの振れ幅や反応のしやすさが調整され、キャラクターの個性として自然に定着していきます。
3. 対話を重ねるにつれて性格や受け答えのニュアンスも徐々に変化し、ユーザー一人ひとりに寄り添った唯一無二のコンパニオンへと育っていきます。

日々の交流を通じて育まれた変化は、そのコンパニオンとユーザーとの関係固有の状態として保持され、[配布用のキャラクター初期設定](create.md)には含まれません。なお、特定の記憶について忘れるよう求めた場合は以後の成長判断にも影響しますが、すでに定着した性格傾向や関係性の変化そのものを直ちに巻き戻すものではありません。
