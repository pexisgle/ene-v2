# キャラクターの成長

日々の対話や共有した体験を通じて、キャラクターの根本を決める「心のコアの定義」をだんだんと更新していく仕組みです。

## 具体的な振る舞い

1. コンパニオンとの日々の対話や、[共に経験した出来事の記憶](../memory/README.md)の蓄積を通じて、キャラクターの性格傾向やユーザーとの関係性が育ちます。
2. [Compaction時の振り返り](../chat/README.md)などのタイミングで、蓄積された記憶や感情をもとにキャラクターの自己認識や対話傾向（心のコア定義）が漸進的に更新・定着していきます。
3. これにより、対話を重ねるにつれて性格や受け答えのニュアンスが自然に変化し、ユーザー一人ひとりに寄り添ったコンパニオンへと育っていきます。

日々の交流を通じて育まれた変化は、そのコンパニオン固有の状態としてホストに保持され、[配布用のキャラクター初期設定](create.md)には含まれません。
