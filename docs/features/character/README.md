# Character

キャラクターを形づくる「体・声・心」の作成・管理と、各クライアントにおける描画・表示を担当する領域です。キャラクターの設定情報はホスト側で一元管理され、描画処理は各クライアントが担います。Webブラウザやスマートフォンアプリでは画面内に表示し、デスクトップクライアントでは画面上への常駐表示も可能です。対応するモデル形式や表現の範囲は、各クライアントのプラットフォーム特性に応じて最適化されます。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| [キャラクターの作成](create.md) | 体・声・心をセットで、または個別に登録し、パッケージとして書き出し・取り込みを行う |
| [感情システム](mind.md) | 感情・関係性・経験を保持し、対話や挙動の補助情報としてLLMに反映する |
| [キャラクターの成長](grow.md) | 日々の対話や経験を通じて、キャラクターの心のコア定義を漸進的に更新する |
| [記憶機能](../memory/README.md) | ユーザーの好みや思い出を記憶し、対話の深まりや成長の糧とする |
| [デスクトップでのキャラクター表示](desktop.md) | デスクトップクライアント上でモデルを常駐させ、生き生きとした仕草を表示する |
| [ホストとクライアント](../hosting/README.md) | キャラクター設定を一元管理し、複数端末から同一のコンパニオンと接する |
| [対話（Chat）](../chat/README.md) | 定義された性格や口調を自然に反映した対話を楽しむ |
| [音声での対話](../voice/README.md) | キャラクター固有の声で発話を受け取り、リアルタイムに会話する |
