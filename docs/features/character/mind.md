# 感情システム

感情表現をLLMの出力だけに委ねるのではなく、ene独自の感情モデルを内部で保持・更新することで、一貫性があり情緒豊かなキャラクター表現を実現します。

## 具体的な振る舞い

1. 対話におけるLLMの応答やユーザーの発言を解析し、喜び・悲しみ・驚きなどの感情パラメータを内部で更新します。
2. 更新された感情状態を、表情や視線、身振りなどのモーションや、音声トーンの制御へ即座に反映します。
3. システムプロンプトへ現在の感情状態や感情の振れ幅を補助情報として渡すことで、文脈から乖離した極端な感情の乱高下や、キャラクター性を損なう不自然な変貌を抑え、一貫性を保ちます。
4. 感情モデルの状態はホスト側で定期的に永続化され、アプリの再起動後や別クライアントからの再接続時にも途切れることなく引き継がれます。
5. ユーザーに対する親愛度や信頼感、他のコンパニオンとの関係性も加味した、深みのある感情表現を行います。
