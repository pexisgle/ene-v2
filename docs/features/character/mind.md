# 感情システム

システム側で複雑な心理モデルや好感度式を固定的に実装するのではなく、システムは**「感情の保持」「関係性の保持」「記憶システムによる経験の保持」**を行い、それらをどう解釈して対話や仕草へ活かすかはLLMに一任します。

感情は、その時々の会話における感情状態を整理し、キャラクターがどのように発話・挙動するかの補助機能として位置づけられます。

## 具体的な振る舞い

1. コンパニオンは新しい発言や出来事を受け取った際、その会話における感情を整理・保持します。単語に対応した固定の加点式や全員共通の数値パラメータではなく、文脈に沿ってLLMが自然に扱います。
2. 感情の状態は、発話のニュアンス、声のトーン、[デスクトップ上での仕草やリアクション](desktop.md)を決定するための補助情報として活用されます。
3. 保持された感情や関係性はホストに保存され、再起動・再接続・会話モデルの変更をまたいで引き継がれます。
4. 日々の対話を通じてキャラクターの根本的な自己像や性格傾向そのものが更新されていく過程は、[キャラクターの成長](grow.md)として扱います。

参考：[心の設計](../../design/mind.md)、[人格・心の調査](../../references.md#alpha-mind)。
