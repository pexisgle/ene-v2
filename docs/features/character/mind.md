# 感情システム

感情を発話のタグだけにせず、キャラクターの人格、[経験の記憶](../memory/README.md)、相手との関係を踏まえて保持・更新します。現在の感情、過去の出来事に残る当時の感情、相手の感情についての推測、表情や声として見せる態度は区別します。

## 具体的な振る舞い

1. コンパニオンは新しい発言や出来事を、人格の核・関連する側面・過去の経験から受け止めます。何に対して、なぜそう感じているのかを扱い、単語に対応した固定の加点で感情を決めません。
2. 受け止め方は記憶・関係性と結び付きます。同じ経験を思い出しただけで出来事が再発生したことにしたり、関係を何度も強化したりしません。
3. 現在の心を次の会話・作業判断へ反映し、相手や状況に応じて表情・視線・身振り・音声トーンを選びます。嬉しくても相手に配慮して静かに話せるなど、感情と表現を一対一に固定しません。
4. 状態はホストに保存され、再起動・再接続・会話モデルの変更をまたいで引き継がれます。過去の自動整理が遅れて完了しても、現在の感情を古い状態へ戻しません。
5. 交流による[関係性や成長](grow.md)は、配布用の初期人格と分離します。親しさや感情によって、任されたアクセス権が増えることはありません。

感情軸・表現語彙・強度の扱いはキャラクターと表現先に合わせて調整します。特定の心理尺度、全員共通の好感度式、毎秒の推論を必須にはしません。表現の補間と、心の意味を変える更新は別です。

実装契約は[心の設計](../../design/mind.md)、選定根拠は[人格・心の調査](../../references.md#alpha-mind)を参照してください。本書は目標となる体験であり、描画・音声を含む実装完了の宣言ではありません。
