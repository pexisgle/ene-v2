# 感情システム

システム側で複雑な心理モデルや固定の好感度式を実装するのではなく、システムは**「感情の保持」「関係性の保持」「記憶システムによる経験の保持」**を行い、それらをどう解釈して対話や仕草へ活かすかはLLMに一任します。

[記憶機能](../memory/README.md)と感情システムが連携することで、人間らしい一貫したリアリティのある挙動を実現します。

## 具体的な振る舞い

1. コンパニオンは会話や出来事を通じて、現在の感情状態やユーザーとの関係性の捉え方を整理・保持します。
2. 感情や関係性の更新は、[Compaction](../chat/README.md)の振り返り処理などに合わせて無理なく更新され、再起動やモデル変更をまたいで引き継がれます。
3. 保持された感情・関係性は、発話のニュアンス、声のトーン、[デスクトップ上での仕草やリアクション](desktop.md)を決める補助情報として活用されます。
4. 長期にわたる性格の核や自己像の変化は、[キャラクターの成長](grow.md)として扱います。

参考：[心の設計](../../design/mind.md)、[人格・心の調査](../../references.md#alpha-mind)。
