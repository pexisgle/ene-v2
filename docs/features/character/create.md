# キャラクターの作成

「体・声・心」の3要素を組み合わせて思い通りのキャラクターを作成し、1つのパッケージとして書き出したり取り込んだりできます。

## 具体的な振る舞い

1. キャラクター登録画面において、用意したVRMなどの3DモデルやLive2Dモデルを「体」として割り当てます。初期実装ではVRMを中心とした3Dモデルを優先し、Live2D対応は順次検討します。
2. 音声合成（TTS）モデルや外部音声エンジンの接続設定を「声」として登録します。用途や場面に合わせて複数の音声プリセットを保持できます。
3. 自己像・価値観・話し方を表す小さな人格の核と、必要に応じて参照する性格の側面・会話や行動の例・背景を「心」の初期プロファイルとして設定します。例は人物像を伝える材料であり、特定入力への固定返答ではありません。これらをユーザーとの実体験や私的記憶として扱いません。
4. これらを統合した「eneキャラクターパッケージ」としてファイルへ書き出せます。配布されたパッケージを別のユーザーが取り込むと、利用するクライアントやエンジンの対応範囲内で、そのキャラクターとの[対話](../chat/character.md)、[描画表示](README.md)、[音声読み上げ](../voice/README.md)をすぐに楽しめます。APIキーなどの秘密情報はパッケージには含めず、取り込み先で利用者が安全に設定します。
5. 登録したキャラクター設定は[ホスト](../hosting/README.md)側で一元管理され、同一ホストに接続した各クライアントから利用できます。

パッケージへ書き出されるのは配布用の初期プロファイルのみです。ユーザー固有の[個人的な記憶や会話履歴](../memory/README.md)、交流を通じて育まれた[性格・関係性の変化](grow.md)はパッケージに含まれません。

参考：[AIRI](../../references.md#airi) における姿と声の統合体験。体・声・心をひとまとめに扱うパッケージ構成はene独自の仕様です。
