# デスクトップでのキャラクター表示

デスクトップクライアントの起動中、お気に入りのキャラクターをデスクトップ上に常駐させ、生き生きとした仕草や表情を楽しめます。[ホスト](../hosting/README.md)が手元のPCにある場合も、外部のVPSや自宅サーバーにある場合も、描画処理は手元のクライアントが軽快に行います。

## 具体的な振る舞い

1. [作成または取り込んだキャラクター](create.md)を読み込むと、登録された「体」が画面最前面に現れ、まばたきや呼吸といった自然な待機モーションを開始します。
2. マウスのドラッグ操作によって、画面上の好きな位置へ自由に移動させることができます。配置場所はクライアントごとに保持されます。
3. キャラクターの輪郭以外の透明領域はマウスクリックを透過するため、背後にあるウィンドウやデスクトップの操作を妨げません。
4. 開いているウィンドウの縁に腰掛けたり、マウスポインタを目で追ったりする仕草に加え、キャラクターの状態や対話内容に応じた多彩なモーション、リアクションを返します。LLMの判断と連携してこうした臨場感あふれる演出を動的に生み出す点が、本ソフトウェアの際立った特長です。

デスクトップ画面上への常駐表示やクリック透過は、デスクトップクライアント固有の機能です。Webブラウザやスマートフォンアプリでは、[それぞれのアプリ画面内へ適切に表示](README.md)されます。

参考：[Desktop Mate](../../references.md#desktop-mate) のデスクトップ常駐と自由な配置、および [AIRI](../../references.md#airi) のモデル描画とアニメーション表現。
