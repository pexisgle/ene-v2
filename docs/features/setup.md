# 環境設定・権限・拡張

この文書では [用語集](../terms.md) の定義に沿って、ホストの配置と複数端末からの利用、プロバイダーとモデルの設定、リスクの明示と操作の確認、およびプラグインによる拡張の機能仕様をまとめます。
会話履歴や記憶、プロバイダーや確認に関する設定はホスト側で一元管理し、表示位置や読み上げのオン・オフといった端末ごとの設定だけを各クライアントに保持します。

## ホストの配置と複数端末からの利用

ホストは手元の PC の裏側だけでなく画面を持たない VPS や自宅サーバーでも常時稼働でき、利用者は PC や Web、スマートフォンから同一のコンパニオンへ接続できます。
ローカル接続では OS 権限で保護された通信経路を用い、遠隔接続では Tailscale Serve や Cloudflare Tunnel + Access などの安全な経路を通して、無保護のままインターネットへ直接公開しません。
こうした安全な遠隔経路は利用者が事前に用意する形を基本としつつ、将来的にはクライアント側へプラグインを追加することで簡単にセットアップできるようにします。
別の端末から呼び出した際はその時点でアクティブな端末へ対話が切り替わり、クライアントを閉じてもホストは稼働を続けて作業やスケジュールを進めます。
接続したクライアントは画面やファイルの操作、知覚センサー、身体表現といった端末能力をホストへ登録して「頭」や「手」から利用できるようにし、未接続時に端末依存の操作が必要になった場合は保留またはエラーとして扱います。
なおホストは個人での利用を前提としており、複数ユーザー間でのホスト共有や複数ホスト間の分散同期は対象外とします。

## プロバイダーの接続と用途別のモデル設定

LLM や音声合成、音声認識、検索、外部連携などの接続先はホスト上のプロバイダーとしてまとめて管理し、認証情報の保存、利用可能なモデル一覧の取得、疎通確認を段階ごとに分けて行います。
クラウド AI やローカル LLM は「頭」の対話、「手」の調査や実務、「目」の知覚評価、および会話の圧縮や記憶の整理という用途別に割り当てることができ、リアルタイムの双方向音声 API は現時点の対象外とします。
疎通確認や利用中に障害が起きた際は認証の不備と外部サービス側の制限を切り分けて原因を示し、設定の見直しや代替モデルへの切り替えを案内する一方で、許可していない外部先へ自動で切り替えることはしません。
設定時には対話文脈や記憶、参照資料のうちどの情報がどこへ送られるかを明示し、API キーなどの秘密情報はホスト側の資格情報ストアで保護して「頭」や「手」、各クライアントへ直接渡さず、ログや記憶にも残しません。

## リスクの明示と操作の確認

安全確認の仕組みとして、危険や迷いのある操作だけを確認する標準の判定モードと、すべての操作を確認なしで実行する FullAccess モードの 2 つを用意します。
標準モードの第 1 段階となる機械的な許可では安全な操作や保存済みの「常に承認」ルールに合う操作を確認なしで実行し、実行環境を隔離する sandbox は実現性を検討中であるため、第 1 段階から利用者へ可否を確認する第 3 段階までの判定を安全確認の基本とします。
第 2 段階では機械的な許可に当たらない操作を LLM が判定し、一般的な安全性と依頼の文脈に加えて「外部への送信は常に確認する」のように利用者が文章で書く自由文ポリシーに反しなければ確認を求めずに進めます。
危険や自由文ポリシーとの衝突が見つかった場合、または LLM による判定がエラーや時間切れになった場合に限り第 3 段階の承認カードを表示し、利用者は「承認」「常に承認」「拒否」から選択して、「常に承認」を選んだ操作は次回から第 1 段階で通ります。
承認カードの回数をなるべく抑えるため大きな作業のまとまりごとに確認を取る方針とし、カードを押すだけでなく会話の中で利用者が同意や拒否を伝えたと「頭」が判断した場合も承認を確定できます。
さらに「ブラウザを使ってメールを確認していいよ」のように会話の中で許可した条件を自由文ポリシーへ自動で追加する仕組みを備え、離席中に発生した確認事項は保留して再接続時の対話や画面からまとめて確認できます。
ツールごとの細かな権限表は設けず、設定画面では自由文ポリシーの編集、保存済みの「常に承認」ルールの確認や削除、および判定履歴の閲覧だけを扱います。

## プラグインによる機能の拡張

ene では「手」「目」「体」の 3 つの領域を中心に、必要な機能をプラグインとして後から追加や差し替えができます。
「手」の拡張では [作業・見守り・スケジュール](tasks.md) で扱う外部ツールや外部サービスとつなぐ MCP、外部の作業エージェントを取り込む ACP の連携などを追加し、「目」ではエディタやブラウザの状況を拾う知覚センサー、「体」では待機モーションや表情、デスクトップ上の仕草を増やすことができます。
利用者は設定画面からプラグインごとに有効化や無効化、差し替えをいつでも行うことができ、導入時にリスクと送信先を確認したうえで、実行時は選択中の標準の判定モードまたは FullAccess モードに従って安全に動作します。
