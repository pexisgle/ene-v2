# 08. PC⇄スマホ引き継ぎ・クライアント能力登録と未接続時保留

VPSや自宅サーバーでホストを常時稼働させ、PC・Web・スマートフォンなど複数クライアントから同一のコンパニオンへ接続・切り替えながら、クライアント固有の能力登録（`RegisterClient`）や未接続時の安全な保留を確認するシナリオです。

## 対象機能

- [ホストとクライアント](../features/hosting/README.md)（ローカル/サーバー運用、Tailscale/Cloudflare等による経路保護、複数クライアントからの接続・切替、切断中の作業・スケジュール継続、`RegisterClient` 能力登録、未接続時のエラー/保留）
- [Tools](../features/tools/README.md)（アクティブクライアントが `RegisterClient` で登録した能力ツールの動的公開・実行）
- [権限とデータの管理](../features/settings/permissions.md)（端末内能力への判定パイプライン適用）

## 前提条件

- VPS または自宅サーバー上で `ene-host`（「頭」「手」「目」の選別、記憶・感情・成長・Compaction を担う）がヘッドレスで常時稼働している。
- 遠隔接続は Tailscale Serve（または Cloudflare Tunnel + Access）で保護されており、無保護のままインターネットへ公開していない。
- PCデスクトップクライアントは起動時に、自分の持つ能力（デスクトップアバターのモーション表現、PCの知覚センサー、PCローカルの端末内ツールなど）を `RegisterClient` でホストへ登録している。

## シナリオの流れ

### 1. 自宅PCから外出先スマホへの接続・切り替え

1. 自宅PCでデスクトップクライアントを使い、コンパニオン「凪」に調査作業を頼んだあと、PCを閉じて外出する。
   - PC上では凪の位置が画面右下に配置され、音声読み上げオンになっていた。
2. 電車の中でスマホアプリから同じホストへ接続し、「凪」を呼び出す。
   - **システム動作**：
     - 別の端末から呼び出されたため、現在のアクティブな端末がスマホ側へシンプルに切り替わる。
     - 表示位置や音声のオン・オフといった表示設定はクライアント側で個別に保持されるため、スマホ側の設定のまま開かれる。
     - 過去の会話履歴・記憶・作業の進捗はホスト側で一元管理されているため、そのままスマホで続きを確認できる。
3. **ユーザー（スマホ・テキスト）**：「さっきPCで頼んでおいた資料のまとめ、どうなった？」
   - **凪（スマホ・テキスト）**：「ちょうど整理が終わったところだよ。要点は3つあって……」
   - ※PCが閉じられていても、ホストが常時稼働しているため任された作業は止まらず完了している。

### 2. クライアント能力の動的公開と判定パイプライン

1. 帰宅して再びPCデスクトップクライアントからホストへ接続する。
   - **システム動作**：PCクライアントが `RegisterClient` で登録した能力（アバターモーション指示、端末内ツール等）がアクティブクライアントの能力としてホストへ認識され、「頭」や「手」からツールとして自動的に利用可能になる。
2. ユーザーがPC上の操作を頼む。
   - **ユーザー（音声）**：「手元のPCの指定フォルダにあるメモを開いて確認しておいて」
   - **システム動作**：端末内能力の実行にも [権限とデータの管理](../features/settings/permissions.md) の判定パイプライン（機械的許可 → Decision API → 必要時のみ承認）が適用され、許可された範囲で安全に実行される。

### 3. 対象能力を持たない／未接続クライアントでの安全な扱い

1. 外出先のスマホやWebブラウザから、PC側にしかないローカルファイル操作やデスクトップ専用表現を伴う指示を出す（PCクライアントは未接続）。
   - **ユーザー（スマホ・テキスト）**：「自宅PCの中にある未整理フォルダを今から片付けて」
2. **システム動作**：
   - 現在アクティブなスマホクライアントにはPCローカルのファイル操作能力が登録されておらず、PCクライアントも未接続であるため、無理に実行しようとせず安全にエラー・保留として理由を伝える。
   - **凪（スマホ・テキスト）**：「いま自宅のパソコンが接続されていないから、そのフォルダにはまだアクセスできないよ。パソコンからつないだ時にまた声をかけてね。」

## 例外・境界ケース

- **ローカル完結運用**：VPS等を使わず1台のPC上でホストとクライアントを同居させる場合も、OS権限で保護されたローカルソケット等を前提に同じ仕組みで動作する。
- **複数ユーザー間共有の除外**：初期段階では個人利用を主眼としており、複数ユーザー間でのホスト共有やホスト間の分散同期は対象外とする。
