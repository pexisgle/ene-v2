# 01. 日常の音声雑談・即時Web検索・割り込みとテキスト切替

デスクトップに常駐するキャラクターへ音声で話しかけ、雑談から最新情報の調べ物へ自然に移り、発話中の割り込みや周囲の状況に応じたテキスト対話への切り替えまでを一続きの体験として確認するシナリオです。

## 対象機能

- [Chat](../features/chat/README.md)（テキスト・ボイス統合対話、軽い即答の完結）
- [音声対話](../features/voice/README.md)（STT/TTS・リアルタイム双方向音声API、VAD / Push-to-Talk、割り込み中断、リップシンク・発話モーション連動、音声入出力の独立オンオフ）
- [Web検索](../features/tools/search.md)（検索要否の自律判断、前置きなしの自然な返答、出典URL、未発見時の簡潔な伝達）
- [デスクトップでのキャラクター表示](../features/character/desktop.md)（最前面常駐、クリック透過、ドラッグ配置、ウィンドウ縁への腰掛け、視線追従）

## 前提条件

- デスクトップクライアントがローカルまたは遠隔のホストへ接続済み。
- コンパニオン「凪」（VRMの「体」、TTS音声プリセットの「声」、穏やかで簡潔な「心」）がデスクトップ最前面に常駐している。
- 音声入力は **VAD（常時発話検出）**、音声読み上げはオン。
- Web検索プロバイダ（APIキー含む）がホストに設定済み。

## シナリオの流れ

### 1. デスクトップ常駐と作業を妨げない配置

1. ユーザーはブラウザやエディタを開いて作業を始める前に、画面中央付近に出ていた「凪」をマウスでドラッグし、開いているブラウザの右上縁へ移動する。
   - **システム動作**：配置位置はクライアントごとに保持される。凪はウィンドウの縁に腰掛ける待機モーションを取り、まばたき・呼吸をしながらマウスポインタを目で追う。
2. ユーザーがブラウザの検索欄をクリックしようとして、凪のモデルの輪郭外の透明領域をクリックする。
   - **システム動作**：透明領域はマウスクリックを透過するため、背後のウィンドウ操作は妨げられない。

### 2. 雑談から自律的なWeb検索への移行

1. ユーザーが作業の手を止めてマイクに向かって話しかける。
   - **ユーザー（音声）**：「あー、ちょっと一息。そういえば今週末、東京の天気って晴れだっけ？」
2. **システム動作**：
   - 音声入力がホスト側の「頭」（キャラクターAgent）のコンテキストへ追加される。
   - 「頭」は最新の天気予報が必要と自律判断し、重い調査（「手」）へ回さず設定済みの検索エンジンで即時検索を実行する。
   - 「ちょっと調べてみるね」といった形式的な前置きを必須とせず、結果を受けてすぐ応答を生成する。
   - 音声出力に合わせて、凪の口元がリップシンクし、発話モーションが連動する。
3. **凪（音声）**：「土曜日は一日晴れみたいだよ。日曜は夕方から雨予報だから、出かけるなら土曜がよさそう。」

### 3. 発話中の割り込み中断と Push-to-Talk への切り替え

1. 凪が続けて週末の話題を話し始める。
   - **凪（音声）**：「もし都内を歩くなら、先週オープンした展示が――」
2. ユーザーが途中で声を挟んで割り込む。
   - **ユーザー（音声）**：「あ、ごめん待って！日曜の雨って夕方何時ごろから降るんだっけ？」
   - **システム動作**：キャラクターの発話中にユーザーが割り込んだため、凪の発話を中断してユーザーの聞き取りへ切り替わる。
3. **凪（音声）**：「17時ごろから降り始める予報だよ。傘は持っていったほうが安心かな。」
4. その後、周囲の音を拾いやすい環境へ移ったため、ユーザーは音声入力方式を **VAD から Push-to-Talk（キーを押している間だけ聞き取る）** へ切り替える。

### 4. 音声のオン・オフ切替と、見つからない情報の扱い

1. ユーザーが静かな会議室に入ったため、デスクトップクライアントで**音声入力と読み上げの両方をオフ**にし、文字入力欄を開く（音声入力と読み上げは独立してオン・オフできるため、片方だけの切替も可能）。
2. ユーザーがテキストで入力する。
   - **ユーザー（テキスト）**：「さっき話してた展示、今日の当日券のリアルタイム残数って公式サイトに出てる？」
3. **システム動作**：
   - テキスト入力も音声入力とひとつの統合された対話体験として処理される。
   - 「頭」はWeb検索を行うが、公式サイト上に当日券のリアルタイム残数情報が公開されていないことを確認する。
4. **凪（テキスト）**：「公式サイトを見たけど、当日券のリアルタイムな残数は載っていなかったよ。参考にしたページはこれね： https://example.com/exhibition 」

## 例外・境界ケース

- **検索結果がまったく見つからない場合**：存在しない情報で補わず、該当する情報が得られなかった旨を簡潔に伝える。
- **テキスト返答時の出典**：出典は本文中のURLにとどめ、過度な装飾や別パネル表示は行わない。
