# ene の構想

## 目的

チャットや調べ物で生成AIが普及した現在も、実務の作業まで自律的に任せる使い方は一部の利用者に限られています。
[Claude Code](https://code.claude.com/docs/en/overview) や [OpenClaw](references.md#openclaw) のような開発者寄り・自律稼働型のツールは導入や運用に前提知識が求められるため、一般の利用者が気軽に使い始めることは困難です。
一方、[Claude Cowork](references.md#claude-cowork)・[Grok Bot](references.md#grok-bot)・[MetaのMuse](https://muse.ai) のようなクラウド型エージェントは特定のクラウドや業務・チャット中心の画面に固定されており、親しみやすいキャラクター性やローカル運用・構成の自由度に乏しい面があります。
そこで ene は [Desktop Mate](references.md#desktop-mate) のようにパソコンの中に暮らす自律したキャラクターを対話のインターフェースに据えます。
キャラクターが実在するかのように振る舞うことでAI活用のハードルを下げ、エージェントの仕組みを意識せずに実務を任せられるようにします。
利用者はプロンプトの記述やツールの設定を行わなくても、日常の雑談や調べ物から情報調査、作業代行、外部ツールの操作までキャラクターとの対話を通じて依頼できます。

## 設計方針

ene は特定のLLMやAIプロバイダー、ツール、キャラクターの形式に縛られず、必要に応じて機能を追加・交換できる構成にします。
また、実行基盤とデータ管理を担う[ホストと、表示・操作を担うクライアント](features/setup.md)を分離して設計します。
1台のPCで完結するローカル運用を標準としつつ、VPSや自宅サーバーでホストを常時稼働させる構成にも対応します。
デスクトップ、Web、スマートフォンなど複数のクライアントから同一のキャラクターへ接続すれば、対話や作業の文脈を端末間で引き継ぐことができます。
また、外部データ送信の制御を含む厳密な権限管理は作り込まず、利用者がリスクを把握したうえで自己責任で運用することを前提とします。

## 想定ユーザー

普段チャットや検索で生成AIを使っているもののエージェント活用には踏み込めていない層を一つの目安としつつ、特定の属性に限定せず幅広い利用者を想定します。
ソフトウェアやAIの専門知識は求めず、親しみやすいキャラクターを通じて心理的なハードルを下げ、迷わず操作できる体験を目指します。

## 主要な価値

- 大規模言語モデルの表現力を活かし、仕草・表情・音声と文脈に応じた応答によって実在感のあるキャラクター表現を行います。
- 日常の雑談から情報収集、調査分析、作業の代行、外部ツールの操作まで、画面入力に限らず将来的な中心となる音声対話を含めたキャラクターとのやり取りで一貫して行うことができます。
- 日常に寄り添うパートナーとしての親しみやすさと、実務を遂行するアシスタントとしての実用性を各キャラクターの中で両立させ、必要に応じて複数キャラクターで役割を分担する使い方にも対応します。
- LLMプロバイダー、作業を実行する外部エージェント、各種ツールやMCPサーバー、音声合成エンジン、3Dモデルなどを目的に応じて組み合わせ、差し替えることができます。
- 利用するLLMやツールのリスクを明示し、通常作業を過度な確認なしで自律的に進めつつ、重要な判断が必要なときだけ対話で確認し、作業はいつでも停止できるようにします。
