# 用語集

eneの仕様および設計ドキュメントで使用する主要な用語と概念を定義します。

## キャラクター

eneにおけるキャラクターは、以下の3つの要素で構成されます。これらを1つのパッケージとしてまとめて管理・配布できます。

- **体（Body）**
  クライアント画面上に描画されるビジュアルモデルです。VRM形式をはじめとする3DモデルやLive2Dモデルなどを指します。デスクトップ画面上への常駐表示は、デスクトップクライアントにおける表示形態のひとつです。
- **声（Voice）**
  キャラクターの発話に用いられる音声表現です。音声合成（TTS）エンジンの接続設定や、音声モデルのプリセット情報を指します。
- **心（Mind）**
  キャラクターの性格、口調、世界観、思考特性を定義するシステムプロンプトや前提知識の設定群です。

## エージェントと実行環境

- **コンパニオン**
  ユーザーの傍らに寄り添い、対話や感情表現を交わす中心的な存在です。セッションはホスト上で常時稼働し、ユーザーは各種クライアントを通じて接します。[Grok Bot](./references.md#grok-bot) における `Bot` に相当します。
- **エージェント**
  コンパニオンの指示のもとで具体的なタスクや調査を実行する、サブエージェントとしてのLLMセッションです。eneとしてのオーケストレーションはすべてホスト側で行われますが、タスクの内容に応じて、各クライアント端末のComputer use（GUI操作）やファイル編集など、クライアント環境に直接作用する操作も担います。エージェントの内部処理は表層には現れず、ユーザーとの窓口はコンパニオンが一貫して担当します。
- **ホスト**
  コンパニオンおよびエージェントの稼働、会話履歴やキャラクター設定、タスクや最終報告の管理、自律実行スケジューリング、外部モデルやツールとの接続を一手に担う常時稼働の実行基盤です。画面を持たないヘッドレス環境でも稼働可能で、ローカルPCのバックグラウンド常駐サービス、あるいはVPSや自宅サーバーなどに柔軟に配置できます。クライアントが切断されてもホストは停止しません。
- **クライアント**
  ホストに接続し、対話やキャラクターの描画、音声の入出力、作業進捗や最終報告の確認、相談への応答を行うアプリケーションです。デスクトップ、Webブラウザ、スマートフォン向けアプリを想定しています。また、ユーザーが許可した範囲において、端末固有の操作権限（GUI操作やファイル操作など）をホストへ安全に提供する役割も担います。

各要素の連携や接続・切断時の振る舞いの詳細は、[ホストとクライアント](features/hosting/README.md)を参照してください。
