# 用語集

eneの仕様および設計ドキュメントで使用する主要な用語と概念を定義します。

## キャラクター

eneにおけるキャラクターは、以下の3つの要素で構成されます。これらを1つのパッケージとしてまとめて管理・配布できます。

- **体（Body）**
  クライアント画面上に描画されるビジュアルモデルです。VRM形式をはじめとする3DモデルやLive2Dモデルなどを指します。デスクトップ画面上への常駐表示は、デスクトップクライアントにおける表示形態のひとつです。
- **声（Voice）**
  キャラクターの発話に用いられる音声表現です。音声合成（TTS）エンジンの接続設定や、音声モデルのプリセット情報を指します。
- **心（Mind）**
  キャラクターの人格の核・側面・会話例・背景と、経験から育つ記憶・現在感情・関係性・傾向を統合する仕組みです。配布する初期プロファイルと、コンパニオンごとに永続化される私的状態は分けます。詳細は[心の設計](design/mind.md)を参照してください。

## エージェントと実行環境

- **コンパニオン**
  ユーザーの傍らに寄り添い、対話や感情表現を交わす中心的な存在です。ホスト上で継続的な文脈を持つ親エージェントとして管理され、軽い操作と作業の委譲も担います。常にLLMを呼び続ける意味ではありません。ユーザーは各種クライアントを通じて接します。[Grok Bot](./references.md#grok-bot) における `Bot` に相当します。
- **エージェント**
  コンパニオンの指示のもとで具体的なタスクや調査を実行する、サブエージェントとしてのLLMセッションです。親からの指示・相談・報告の仲介はホストで行い、作業内部の分解やサブエージェントは利用するハーネスに任せます。タスクの内容に応じて、各クライアント端末のComputer use（GUI操作）やファイル編集など、クライアント環境に直接作用する操作も担います。エージェントの内部処理は表層には現れず、ユーザーとの窓口はコンパニオンが一貫して担当します。
- **ホスト**
  コンパニオンおよびエージェントの稼働、会話履歴やキャラクター設定、タスクや最終報告の管理、自律実行スケジューリング、外部モデルやツールとの接続を一手に担う常時稼働の実行基盤です。画面を持たないヘッドレス環境でも稼働可能で、ローカルPCのバックグラウンド常駐サービス、あるいはVPSや自宅サーバーなどに柔軟に配置できます。クライアントが切断されてもホストは停止しません。
- **クライアント**
  ホストに接続し、対話やキャラクターの描画、音声の入出力、作業進捗や最終報告の確認、相談への応答を行うアプリケーションです。デスクトップ、Webブラウザ、スマートフォン向けアプリを想定しています。また、ユーザーが許可した範囲において、端末固有の操作権限（GUI操作やファイル操作など）をホストへ安全に提供する役割も担います。

各要素の連携や接続・切断時の振る舞いの詳細は、[ホストとクライアント](features/hosting/README.md)を参照してください。

## Alpha設計で区別する単位

| 用語 | 意味 |
| --- | --- |
| BackendProfile | 作業実装、認証、モデル、ツールなどの設定。作業一件ではない |
| WorkSession | 親に属する作業相手との継続的な文脈。同じ設定から複数起動できる |
| Run | 入力から始まる一回の処理。正常な応答終了と目的達成は別 |
| 経験の根拠 | 出所・取得方法・時刻を持つ入力や結果。内容の真実性が保証されるとは限らない |
| 記憶 | 経験、事実、解釈、合意、手順を由来とともに保持したもの。会話ログや検索索引とは別 |
| 現在の心 | 今の感情、関係性・成長、関心をまとめた状態。発話の表情指示とは別 |
| 自動整理 | 保存済みの未処理経験から記憶を形成する有限の内部処理。別の常設人格ではない |

操作とイベントの意味は[作業API](design/work.md)、記憶の更新は[心](design/mind.md)に集約します。
