# 第1段階：Slint会話画面の実装と検証

対象はLinux／Waylandです。[アーキテクチャ](architecture.md)・[ホストAPI案](api.md)を保持し、Nix関連の変更は行っていません。

計画の「最初の実装単位は第1段階に限定し、その完成確認後に順次進める」に従います。第1段階の実装と自動検証、KDE/KWin＋Fcitx5＋Hazkeyの実機受け入れ、音声付きMVP全体の完成は別の状態です。実機受け入れが未確認の間、第2～5段階の実装へ進んだことにはしません。

## 実装済みの範囲

- Slint／slint-build 1.18.1を固定。Slintの既定機能を無効化し、`std`、`compat-1-2`、`backend-winit-wayland`、`renderer-femtovg-wgpu`、`system-tray`を有効化。ビルド時に`.slint`をコンパイルします。Qt・UIインタープリターは導入していません。
- 会話一覧、複数行入力、送信ボタン、状態表示。Enterは改行で、IMEの確定・取消キーを送信に割り当てません。Unicodeの空白だけの本文を拒否し、受付後は入力をクリアしてフォーカスを戻します。本文の改行・前後の空白は保持します。
- 明示的な`--demo`モードだけで固定の日本語応答を返し、画面と返答に「仮応答」を表示します。通常起動はホスト未接続です。会話はメモリ内だけに保持し、終了時に失われることを画面で伝えます。
- Slintの`SystemTrayIcon`。クリック・メニューから会話表示、メニューから設定・クライアント終了。登録が確認できた場合のみ×で非表示にします。非表示でもイベントループを継続します。
- Slint 1.18.1は登録失敗を公開プロパティとして返さないため、別スレッドでStatusNotifierWatcherに登録された項目のプロセスIDを確認します。トレイホストの存在だけでは成功としません。確認結果には2秒の有効期限を設け、登録消失・応答遅延では画面を再表示します。D-Bus呼び出しは500msでタイムアウトし、確認結果の待機列は1件に制限します。
- `Noto Sans CJK JP`を既定の日本語フォントとし、設定画面でフォント名と文字サイズを変更できます。設定はこの段階では起動中のみ有効です。
- 設定画面に標準の`AboutSlint`を表示します。採用ライセンスは[Slint Royalty-free License 2.0](../licenses/Slint-Royalty-free-2.0.md)です。eneのアイコンはこのリポジトリで作成したものです。

## 再現手順

```sh
just verify
just run-desktop
# 同じ起動方法（justなし）
cargo run --locked -p ene-desktop -- --demo
```

Waylandの表示先、セッションD-Bus、日本語フォント、Vulkan対応ドライバーが必要です。Nixを使わない環境の開発用依存はREADMEに記載しています。`--help`は描画環境なしでも使用できます。

初期実装時にはWayland描画・入力と専用D-Busでのトレイ統合試験を実行しました。一度限りの検証用テストとコマンドは削除し、入力・設定などの通常の回帰テストは`just verify`に残しています。以下は当時の検証記録です。ネイティブIMEの候補表示・preedit・確定・取消は実機試験が必要です。

## クラウド環境の検証記録

検証日：2026-10-01（日本時間）。Rust 1.98.1、Debian 13、Weston 14.0.2のheadlessバックエンド＋desktop-shell、Slint 1.18.1、FemtoVG/WGPU、Mesa 25.0.7のLavapipeを使用します。クラウドには物理GPUもKDE/KWin・Fcitx5＋Hazkeyセッションもありません。

物理GPUがない環境で描画試験を再現する場合は、インストール済みのMesa Vulkanドライバーを用意し、`SLINT_WGPU_CPU=1 WGPU_BACKEND=vulkan`を試験コマンドに付けます。この設定を製品の通常起動では強制しません。ライブラリをユーザーの一時ディレクトリへ展開して検証したため、クラウドの管理者権限でのパッケージインストールは行っていません。

Westonのkiosk-shellでは設定ウィンドウが会話画面を完全に覆い、LavapipeのWayland presentationが待ち続ける事象を確認しました。GDBでVulkanの`queue_present`から`wl_display_dispatch_queue`を待っていることを確認し、通常のdesktop-shellで試験を実行します。この違いはKWin上の動作確認の代わりにはなりません。

## UI/UX改善（2026-10-01）

会話画面から非表示・終了ボタンと独立した状態表示・利用表示の行を取り除き、会話領域を優先しました。×でトレイへ隠し、終了はトレイメニューから行います。トレイが利用できない場合のみ、設定画面に終了ボタンを表示します。登録状態の変化は開いている設定画面にも反映します。

入力欄と送信ボタンを一つのパネルにまとめ、入力パネルは本文量に合わせて86〜180pxへ伸縮します。長文では入力欄内をスクロールできます。発言カードは本文に合う高さに留め、ウィンドウの拡大分は会話領域へ割り当てます。Slintの利用表示は設定のAboutSlintから確認できます。

追加の描画検証では、20行の入力、960×820の拡大、420×480・文字サイズ28の縮小表示を確認しました。`just verify`（7件成功・GUI2件は別実行）、Wayland描画試験、トレイ試験はすべて成功しました。検証ログは`validation/desktop-uiux-2026-10-01.txt`、キャプチャは`target/desktop-smoke-{after,long-input,large,compact}.png`に保存します。ネイティブIMEの実機確認は引き続き未実施です。

第2段階では表示設定を端末へ保存するよう変更し、VRM・表示切替・fps・再起動を追加しました。現在の動作は[第2段階の記録](avatar-stage2.md)を参照してください。
