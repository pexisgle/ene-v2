# 設定ウィンドウ 表面ブリーフ

状態: 2026-11-18 決定（shape）。方向は **canon（カテゴリ標準を全力で）**、ユーザー指定の性格は **kawaii**。
モード: Operate。ビルド: code-led（gpui、comp なし）。

## 1. 仕事と相手

- 初回: AIに心理的抵抗はないが、専門知識のない日本語ユーザーが「つながって、話せるところまで」辿り着く。
- 以降: 同じ人が「何をどこまで任せているか」を確かめ、必要な一行だけを変える。
- 両立の解き方: 画面は一つ。初回の案内は**章の先頭に居座る導入レイヤ**として現れ、全役割が接続できた時点で自分から消える（消す操作を要求しない）。

## 2. 成果と証明

- 成功: 切断行を見つけた人が、他の画面もドキュメントも開かずに直せる。行の中に理由と再接続が同居している。
- 初回の成功: 章02を上から辿るだけで接続が完了し、章04で「この端末で話す」を押すと会話に戻れる。
- 証明は実物で行う。モデル名・役割・話者・状態語は実データをそのまま出す。飾りのチャートや要約数値は置かない。

## 3. 選んだ方向

**骨格はカテゴリ標準、性格は kawaii。** 標準を衒いなく仕上げたうえで、製品固有の表現を一つだけ通す。

- 品質の基準: macOS システム設定（行の粒度と状態の見せ方）、Linear（密度・キーボード・静かな強調）、Raycast（小さく完結する道具の手触り）。
- 性格の基準: Desktop Mate / Project AIRI の kawaii。柔らかい面、丸い角、やさしい言葉、キャラクターが隣にいる。
- 構図: 左に章レール（200px 固定）、右にペイン（最大 720px）。行 = ラベル + 補足 + 右寄せコントロール。
- 焦点: 常駐するコンパニオン。章レールの最上部に小さく居て、章の切替・保存・エラーに短く反応する。押すと会話へ戻る。操作は絶対に邪魔しない。
- 実装への帰結: 色と角丸と影をトークンに集約し、画面は「行データを描く」構造へ。`SettingsSection` を5章に再編する。

kawaii の具体（ここを曖昧にすると凡庸なピンクになる）:

- 地 `#FBF7F5`（白にほんのり桜）、面 `#FFFFFF`、罫 `#E8DFDA`、文字 `#33292B`（純黒を使わない）。
- 操作色は一つだけ `#E8597A`。押せるものにしか出さない。補助に `#5FB3A1`（成功・完了）。
- 状態は言葉で持ち、色は補強: 接続中 `#3F8F6B`、接続しています `#C98A2B`、切断 `#C2453F`。
- 角丸は面 14px、コントロール 10px、トグルとチップ 999px。影は暖色寄りの低いもの一つ。
- 書体は OS 同梱（游ゴシック）。本文 13/15、章題 18 semibold、説明 12 で行間 1.7。
- アイコンは 1.5px の丸い線。文字の無いアイコンボタンは作らない。
- 文言は「〜できます」「〜してください」。エラーに感嘆符を付けない。褒めない。

## 4. 範囲と境界

- 対象: 設定ウィンドウのみ。会話・名簿は次の段階（同じ世界を継承する）。
- 仕上げ: 5章すべてが production-ready。モックや仮データは残さない。
- 動く: トグル、選択、キー登録と削除、再接続、話者選択、テスト再生、承認ルールの削除、ポリシー1行の保存。
- 触らない: ホストAPIの契約、revision による競合解決、保存の意味論。実装は書き直すが、これらの意味は変えない。
- 反目標: 権限マトリクス、設定のダッシュボード化、6章目を足すこと、装飾のアニメーション、独自スクロールバー、モーダルの多用、アイコンだけの操作。

## 5. 状態と幅

- 接続 0件（初回）/ 4件（典型）/ 6件（最大）。1行の高さは 56–72px、1章あたり最大 20行。
- 状態語: 未設定・接続しています・接続中・切断・キー無効・他端末で変更。
- 承認: ポリシーは1行（空も可）。常に承認ルールは 0 / 12 / 50件。0件は空状態の説明を出す。
- 音声: 話者 0（未選択）/ 1 / 30。未選択のときテスト再生は押せない。
- 読み込み中と競合: 行を消さずに、行の中で状態を差し替える。

## 6. 操作と配置

- 章: `01 コンパニオン / 02 サービス接続 / 03 音声 / 04 この端末 / 05 承認`。上下キーと Ctrl+1..5 で移動。Esc で会話へ。
- 01 には「新しいコンパニオン」を章として置かず、作成の入口を一行として置く。
- 02 の先頭にだけ導入レイヤ（未接続の役割があるときだけ): サービスを選ぶ → キーを登録 → モデルを選ぶ。
- 切断行は必ず同じ行に理由と `再接続` を持つ。再接続は行内で進行し、成功すると状態語が変わる。
- 送信・保存は即時。競合したら行に「他の端末で変更されました — 読み直す」を出す。
- 破壊的操作（キー削除、ルール削除）だけ確認を挟む。
- フォーカスリングは 2px。文字は 4.5:1 を満たす。状態は色だけで伝えない。

## 7. 制約と、まだ決めていないこと

- gpui は標準ウィジェットを持たない。ボタン・トグル・選択の見た目とキーボード挙動は自前で守る。
- フォントは OS 同梱を使う（游ゴシック）。埋め込みは必要になった時点で判断する。
- ライトテーマのみ。ダークは今回の範囲外であることをコード上で明示する。
- 未決定: 常駐コンパニオンの表現（静止画か、短いアニメか、VRM 直描画か）。ウィンドウ最小サイズ。英語UIの要否。
